*Settings › ERPLibre › Doctor*: « Start an analysis »
runs the checks and opens the report; the block shows the summary of the
last report and links to it.

The reports are under "🧰 Dev › ERPLibre › 🩺 Doctor", where « New
analysis » runs another one. On a report, « Install the missing modules »
installs every suggested module that can be, « Install » on a line one of
them; both go through a confirmation that lists the scheduled changes,
then installs and reloads the page, or cancels the marks.

The doctor and its reports are for the members of
*Administration / Settings*.
