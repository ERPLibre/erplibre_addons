=========================
LinkUp — Public community
=========================

Opens a LinkUp instance to a public community.

* Public sign-up with e-mail verification and rate limits.
* Consents, profile and pseudonyms of the member.
* Report and block screens, and a moderation console.
* Export and deletion of the member's own data.

Status
======

Skeleton: the module installs and declares its dependencies:
``mail_linkup_reflet``,
``mail_linkup_gamification``.
Its features are not implemented yet.
