=====================
LinkUp — Network view
=====================

Adds the LinkUp Network view to Discuss.

* A client action draws the graph centred on the current member.
* The server computes the graph, the link density and the rankings.
* A link card offers the contact actions allowed by the link.

Status
======

Skeleton: the module installs and declares its dependencies:
``mail_linkup_gamification``,
``mail_linkup_reflet``.
Its features are not implemented yet.
