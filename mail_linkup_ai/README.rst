===============================
LinkUp — Optional AI assistance
===============================

Adds optional AI assistance to LinkUp reflections.

* An abstract provider interface accepts a local model or an external API.
* Suggestions run only with the consent of both members.
* A log records each call without its content.

Status
======

Skeleton: the module installs and declares its dependencies:
``mail_linkup_reflet``,
``mail_linkup_community``.
Its features are not implemented yet.
